기본 정보

이미지

PNG·JPEG·WebP, 각 5MB 이하. 업로드 후 공연을 저장해 주세요.

추가 상세 이미지

원본의 예매 공지·출연진·공연장 사진 영역에 표시됩니다. PNG·JPEG·WebP, 각 5MB 이하.

공연 회차

날짜와 시간은 한국시간입니다. 신청이 있는 회차는 일정을 변경하거나 삭제할 수 없습니다.

방문자가 캘린더형·리스트형을 자유롭게 전환할 수 있습니다.

좌석등급·가격·수량

좌석도 미등록 공연은 회차별 판매 수량을 입력합니다. 지정좌석 공연의 수량은 아래 좌석 배치에서 자동 계산됩니다.

등급 이름가격(원)수량(매)색상

공연장 구역도 불러오기

공연장을 선택한 뒤 양식을 불러오세요. 좌석 배치와 등급을 사본으로 가져오며, 이후 변경은 이 공연에만 적용됩니다.

상세 내용

공개·예매 설정

공개하면 메인 목록과 검색에 표시됩니다. 비공개로 바꾸면 새 신청이 중단되며 기존 내역은 보존됩니다.

저장하면 서버에 반영됩니다.

예매 신청 내역

결제·발권이 진행되지 않은 신청 내역입니다. 최근 1,000건을 표시합니다.

구역도 양식 불러오기

현재 편집 중인 좌석 배치와 좌석등급을 선택한 양식의 사본으로 바꿉니다. 공연 저장을 눌러야 해당 공연에 반영됩니다.

공연 삭제

공연 목록과 예매 화면에서 제외됩니다. 기존 예매 내역은 보존되며 삭제한 공연에서 복원할 수 있습니다.
